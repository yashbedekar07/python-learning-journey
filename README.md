# Python Learning Journey 🐍

My structured path from Python basics to advanced topics, written as runnable, fully commented programs.
Every file starts with a **definition** of the topic, followed by **examples** and **key points to remember**.

## 📂 Structure

| Folder | Topics |
|---|---|
| `01_basics` | print & comments, variables, data types, input/output, operators, strings, lists, tuples & sets, dictionaries, conditions, loops |
| `02_functions_and_modules` | functions, `*args`/`**kwargs`, scope, lambda/map/filter/reduce, recursion, modules & packages |
| `03_intermediate` | comprehensions, enumerate/zip/sorted, nested data, file handling, CSV & JSON, exceptions, datetime |
| `04_oop` | classes & objects, encapsulation, inheritance, polymorphism, abstraction, dunder methods, class & static methods |
| `05_advanced` | iterators & generators, decorators, context managers, type hints & dataclasses, regex, collections & itertools, venv & pip |
| `06_practice_problems` | beginner exercises with solutions |
| `notes` | mistakes and key learnings |

## ▶️ How to run

Requires **Python 3.10 or newer**.

```bash
python 01_basics/01_hello_and_comments.py
```

`01_basics/04_input_output.py` asks for keyboard input (name and age).

## 🧠 How I study each file

1. Read the definition at the top
2. Type the code myself (no copy-paste) and run it
3. Change something and see what happens
4. Write down mistakes in `notes/mistakes_and_learnings.md`
